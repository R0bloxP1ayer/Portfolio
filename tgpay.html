Developer API

Simple enough for a weekend project.

One HTTP request to create a payment link. Webhooks for status updates. SDKs for Python, Node.js and Go.

  • REST API + WebSocket streams
  • Idempotent payment creation
  • Automatic currency conversion
  • Signed webhook payloads
  • Sandbox environment
POST /v1/payments 200 OK 
fetch('https://api.tgpay.io/v1/payments', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_KEY',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    amount: 2900,      // cents
    currency: 'USD',
    methods: ['ton', 'usdt', 'card'],
    webhook_url: 'https://yourbot.com/hook',
    telegram_user_id: 123456789
  })
});
// Response:
// { payment_url: "https://t.me/TGPayBot?start=pay_xxx" }
